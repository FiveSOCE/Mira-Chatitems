Clickable, view-only chat links for player items and storage.

## Player usage

Use these tokens in normal chat:

- `[item]` - held item
- `[inv]` or `[inventory]` - inventory snapshot
- `[echest]` or `[enderchest]` - ender chest snapshot
- `[backpack]` - active worn MiraBackpack snapshot

Links are temporary and open read-only inventories. Snapshot lifetime is configurable in `config.yml`.

Requires MiraCore. MiraBackpacks is optional.
